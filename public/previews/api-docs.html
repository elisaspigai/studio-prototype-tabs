Budgets API

OpenAPI 3.1 · /v1/budgets

GET /v1/budgets
List workspace budgets with period filter and pagination.
POST /v1/budgets
Create a budget category with cap and alert threshold.
PATCH /v1/budgets/{id}
Update cap, threshold, or archive a budget line item.
GET /v1/budgets/{id}/alerts
Fetch triggered alerts for a budget in the current period.
